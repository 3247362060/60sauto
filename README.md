# 60秒读懂世界自动发布脚本（Typecho）

一款 **极简、稳定、高颜值** 的 Typecho 每日 60s 新闻自动发布工具，无需插件安装，单文件部署、全自动更新、兼容所有 Typecho 版本。

## 📌 项目简介

本项目为 **Typecho 专属 60秒读懂世界自动发布解决方案**，替代各类臃肿插件。
仅需一个 PHP 文件即可实现 **每日自动采集、自动配图、自动分类标签、自动发布、日志分页管理**，零人工干预。

适合个人博客、资讯博客、日常记录站点 **每日自动更新内容、提高站点活跃度**。

## ✨ 核心功能

### 🎯 全自动发布
- 每日自动采集最新 60s 全球资讯
- 自动下载远程配图至本地服务器（防图片失效）
- 自动组装 Markdown 格式正文、微语、日期
- 防重复发布机制，同一天不会重复生成文章

### 📑 智能分类 & 标签系统
- 兼容 **分类名称 / 分类缩略名** 双识别
- 自动绑定分类、自动更新分类统计计数
- 自动创建并绑定自定义标签
- **彻底解决旧版脚本后台不显示分类勾选问题**

### 🛡️ 全版本兼容
- 完美兼容 **所有低版本 Typecho**
- 移除高版本专属函数，杜绝 `expr()` 报错
- 自动识别数据表前缀，不挑数据库配置

### 🎨 高颜值可视化后台面板
- 全新重构美化 UI，卡片式简约设计
- 移动端自适应
- 日志分页展示（默认每页10条）
- **一键清空日志功能（带二次确认防误删）**
- 正确适配伪静态，日志文章链接自动适配站点链接结构

### ⚙️ 高灵活配置
- 自定义管理员密钥、任务密钥
- 自定义发布作者UID
- 自定义分类、自定义标签
- 支持多 API 备用轮询，接口挂掉自动切换
- 支持「直接发布 / 保存草稿」两种模式

## 📁 目录结构

```
├── 60sauto.php        # 主程序+后台面板
├── 60s_config.json    # 自动生成配置文件
└── 60s_log.json       # 自动生成运行日志
```

## 🚀 安装教程

1. 将 `60sauto.php` **上传至 Typecho 网站根目录**
2. 访问后台地址完成初始化配置
3. 设置宝塔 / 服务器定时任务，每日自动执行

### 后台访问地址

```
https://你的域名/60sauto.php?admin=1&key=你的管理员密钥
```

> ⚠️ 默认管理员密钥为 `admin888`，部署后请务必在后台面板中修改！

## ⏰ 定时任务配置

**执行频率：每天一次**

```
https://你的域名/60sauto.php?key=你的任务密钥
```

> ⚠️ 默认任务密钥为 `task123456`，部署后请务必在后台面板中修改！

## 📝 配置项说明

| 配置项 | 说明 |
|--------|------|
| 管理员密钥 | 用于登录后台控制面板 |
| 任务调用密钥 | 用于定时任务安全调用 |
| 作者UID | 文章发布作者ID，默认1 |
| 分类名称/缩略名 | 自动绑定文章分类 |
| 文章标签 | 自定义批量标签，逗号分隔 |
| API列表 | 支持多接口备用轮询 |
| 直接发布 | 开启直接上线，关闭存草稿 |
